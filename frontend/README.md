# HackiBits - Cybersecurity Education Platform

**Tagline:** Learn. Build. Secure.

## 🚀 About

HackiBits is a Made-in-India cybersecurity education and hardware innovation brand that democratizes cybersecurity education by creating affordable, modular, and ethical hacking hardware kits for students.

## 🎨 Brand Identity

- **Primary Color:** `#007BFF` (Cyber Blue)
- **Secondary Color:** `#0A0F1F` (Deep Navy)
- **Accent Color:** `#00FF9C` (Electric Green)
- **Typography:** Orbitron (Display), Poppins (Headings), Inter (Body)

## 🛠️ Tech Stack

- **Framework:** Next.js 16
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🌐 Pages
